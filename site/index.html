The tools that hold the bricks together.

mortar.ch is home to the tooling behind BitsAndBricks: the things that keep a pile of repositories in line, so the projects themselves can stay small. For now that is one tool, mason.

mason

One mason command for every repo across your orgs and user accounts: status, pull requests, merges, workflow runs and approvals, releases, security alerts, stats, and drift checks against a shared set of defaults kept in a repo you choose.

cli
mason status, mason prs, mason merge, mason doctor --fix, …
tui
mason tui: every view full screen, keyboard only, htop-style F-keys
web
mason serve: the same in a browser, signed in with your own GitHub or GitLab account. Runs at mason.mortar.ch

$ man mortar

NAME
mortar — the paste between the bricks that holds a wall together
DESCRIPTION
BitsAndBricks makes the bricks. Mortar is what goes between them. A mason is the one who lays bricks in mortar, so the first tool here is called mason. The project started out under the name Mortar itself; the tool became mason, and the name moved up to the domain.
